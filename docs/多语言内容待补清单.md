# 多语言内容待补清单

本文件说明**哪些内容已翻译、哪些待补、补成什么格式**。查阅前请先读 [README](../README.md) 的「多语言」一节。

## 当前覆盖情况

| 内容类型 | zh-CN | en-US | ug-CN | kk-CN | bo-CN | mn-CN |
|---|---|---|---|---|---|---|
| 界面文案（步骤、按钮、提示、错误信息、快捷提问） | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 知识库专业内容（病名、症状、病因、防治、用药） | ✅ | ✅ | ⏳ | ⏳ | ⏳ | ⏳ |
| 语言名称与字体回退链 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

⌛ = 缺失时**自动回退中文**，不会出现空白字段。回退链定义在 `backend/app/constants.py` 的 `FALLBACK_CHAIN`。

## 为什么不直接机翻

病名、症状描述、农药稀释倍数与安全间隔期，机翻出错会直接导致**用错药、用错量**。这类内容必须由「母语者 + 当地农技员」交叉校对。所以本项目宁可不填、走中文回退，也不生成看起来像那么回事但没人能验证的译文。

## 待补内容清单

文件：`backend/knowledge/pest_disease.json`

需要补 4 种语言（`ug-CN` / `kk-CN` / `bo-CN` / `mn-CN`）× 16 个类别 × 5 个字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | 字符串 | 病害/虫害名称，同一作物全称要统一 |
| `symptoms` | 字符串数组 | 3 条，每条一句，描述肉眼可见的症状 |
| `cause` | 字符串 | 一句话说清发病条件（温湿度、栽培因素） |
| `treatment` | 字符串数组 | 4 条，必须包含非化学措施，按操作顺序排 |
| `pesticide` | 字符串数组 | 2~3 条，格式「药剂名 + 稀释倍数」，生物制剂标注出来 |

16 个类别：番茄早疫病、番茄晚疫病、黄瓜白粉病、玉米大斑病、苹果黑星病、柑橘溃疡病、稻瘟病、小麦白粉病、缺氮黄化、缺磷紫红、蚜虫、红蜘蛛（叶螨）、褐飞虱、玉米螟、农药药害、未见明显异常。

### 补写格式

在对应类别的语言块里补齐即可，**缺的语言不用占位空字符串，直接不写这个 key**，程序会走中文回退：

```json
{
  "key": "tomato_early_blight",
  "name": {
    "zh-CN": "番茄早疫病",
    "en-US": "Tomato early blight",
    "ug-CN": "（待补）",
    "kk-CN": "（待补）"
  },
  "symptoms": {
    "zh-CN": ["...", "...", "..."],
    "en-US": ["...", "...", "..."],
    "ug-CN": ["..."]
  }
}
```

同为知识库的 `fertilizer.json`（4 个营养元素）与 `crop_calendar.json`（4 种作物 × 每月农事）同样待补。

补完后把 `pest_disease.json` 顶部的 `i18n_status` 里对应语言从 `"pending ..."` 改成 `"complete"`，便于 `GET /api/system/info` 对外如实反映覆盖度。

## 校验覆盖度

补完后跑一下，看每个语言的字段有没有漏：

```bash
cd backend
python -c "
import json
from pathlib import Path
data = json.loads(Path('knowledge/pest_disease.json').read_text(encoding='utf-8'))
langs = ['zh-CN', 'en-US', 'ug-CN', 'kk-CN', 'bo-CN', 'mn-CN']
fields = ['name', 'symptoms', 'cause', 'treatment', 'pesticide']
print(f'{\"lang\":8} ' + ' '.join(f'{f:10}' for f in fields))
for lang in langs:
    row = []
    for f in fields:
        hit = sum(1 for c in data['classes'] if c.get(f, {}).get(lang))
        row.append(f'{hit}/{len(data[\"classes\"])}')
    print(f'{lang:8} ' + ' '.join(f'{v:10}' for v in row))
"
```

输出里 `16/16` 表示该字段该语言已补满。

## 界面文案的补充位置

界面词条在 `frontend/src/kiosk/i18n/index.js`，结构是 `{ 'zh-CN': {...}, 'en-US': {...}, ... }`。新增界面文案时**必须 6 种语言一次补齐**，不要只写中文。

后台还有一张 `lang_resources` 表（管理后台 → 多语言资源），可以在**不改代码**的情况下覆盖前端内置词条，适合上线后临时纠正某条译文。
